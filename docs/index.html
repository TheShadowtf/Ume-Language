Ume Language

Fast. Expressive. Native.

A statically-typed, C#-inspired language that transpiles to optimized C++17. Write modern, expressive code without sacrificing raw performance.

A taste of Ume

[Serializable]
public class Player {
    [JsonProperty("user_id")]
    public int id;
    public string name;

    // Expression-bodied property
    public bool isMaxLevel => this.level >= 100;
}

public class Main {
    public static func void main() {
        var p = new Player();
        p.id   = 1;
        p.name = "Alice";

        // Serialize to JSON
        string json = p.toJsonString();
        Console.println(json);
        // {"user_id":1,"name":"Alice"}
    }
}
