Standard Library

Math & Random

The Math static class provides standard mathematical functions and constants. Random is a pseudo-random number generator. Both have a basic always-available form (natively backed) and an extended form via import std.math.*;.

Two ways to import the extended Math
import std.math.*;   // AST-level (recommended) — adds E, TAU, absi, log2, etc.
#include <math.ume>   // textual include (C-style)

Basic Math (PI, sqrt, pow, abs, floor, ceil, round, sin, cos, tan, log, log10, min, max, clamp) is always available without any import.

Math

The basic Math is always available without an import — it provides PI, sqrt, pow, abs, floor/ceil/round, sin/cos/tan, log, and min/max. Importing std.math.* replaces it with an extended version that adds E, TAU, cbrt, exp, log2, log10, asin/acos/atan/atan2, minf/maxf, clamp, lerp, toRadians/toDegrees, isNaN, and isInfinite.

// Basic Math is always available
Console.println(Math.PI);           // 3.14159...
Console.println(Math.sqrt(16.0));   // 4.0

// Trig (angles in radians)
double angle = Math.PI / 4;         // 45 degrees
Console.println(Math.sin(angle));   // 0.707...
Console.println(Math.cos(angle));   // 0.707...

With the import, the extended functions become available:

import std.math.*;

Console.println(Math.E);            // 2.71828...
Console.println(Math.log(Math.E));  // 1.0  (natural log of e)
Console.println(Math.exp(1.0));     // 2.71828...  (e^1)
Console.println(Math.absi(-42));    // 42

double deg = 90.0;
double rad = Math.toRadians(deg);
Console.println(Math.sin(rad));     // 1.0

// Linear interpolation
double t = 0.5;
Console.println(Math.lerp(0.0, 100.0, t));   // 50.0

Random

A pseudo-random number generator. Construct with a seed for deterministic output (useful for tests and reproducible procedural generation), or without a seed to seed from the system clock. The extended Random in std.math adds overloads for range-bounded ints and doubles.

MethodSignatureDescription
constructorpublic func void constructor(int? seed)Null seed = clock; non-null = fixed seed.
nextIntpublic func int nextInt()Random non-negative int.
nextIntpublic func int nextInt(int max)Random int in [0, max).
nextIntpublic func int nextInt(int min, int max)Random int in [min, max). (extended)
nextDoublepublic func double nextDouble()Random double in [0.0, 1.0).
nextBoolpublic func bool nextBool()Random true/false.
 
import std.math.*;

// Seeded — same sequence every run
Random rng = new Random(42);
Console.println(rng.nextInt(100));   // e.g. 33
Console.println(rng.nextInt(100));   // e.g. 71
Console.println(rng.nextInt(100));   // e.g. 5

// Unseeded — different each run
Random dice = new Random(null);
int roll = dice.nextInt(1, 7);       // 1 to 6 inclusive
Console.println($"You rolled a {roll}");

bool lucky = dice.nextBool();
double fraction = dice.nextDouble();
Console.println($"lucky={lucky}, fraction={fraction}");

The std.random package

There's also a separate std.random package providing an alternate Random class implemented entirely in Ume source (a 64-bit linear congruential generator). It exposes a few extra methods (nextIntMax, nextIntRange, nextDoubleRange, shuffleInts). Use it if you want a pure-Ume implementation you can inspect or modify:

import std.random.*;

Random rng = new Random();                 // clock-seeded
int die = rng.nextIntRange(1, 6);          // [1, 6)
double pct = rng.nextDoubleRange(0.0, 100.0);

int[] cards = [1, 2, 3, 4, 5, 6, 7, 8];
rng.shuffleInts(cards);                    // Fisher-Yates in-place
