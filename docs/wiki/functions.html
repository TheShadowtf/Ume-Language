Functions

Functions are the basic unit of reusable behavior. A function has a name, a list of parameters, a return type, and a body. Ume supports overloading, default parameter values, variadic parameters, and generic functions.

Declaring a function

The func keyword introduces a function. The syntax is func ReturnType name(params) { … }. A function that doesn't return a value uses void as the return type and either omits the return statement or uses a bare return;.

func int add(int a, int b) {
    return a + b;
}

func void greet(string name) {
    Console.println("Hello, " + name + "!");
}

// Bare return inside a void function
func void maybeLog(string msg, bool verbose) {
    if (!verbose) return;
    Console.println(msg);
}

Functions can be declared at the top level of a file (free functions) or as members of a class (methods). Free functions are visible anywhere in their package; methods are accessed through an instance (or the class name, if static).

Parameters

Parameters are declared as Type name inside the parentheses. Multiple parameters are comma-separated. Each parameter is a fresh local variable initialized with the corresponding argument value when the function is called.

func double distance(double x1, double y1, double x2, double y2) {
    double dx = x2 - x1;
    double dy = y2 - y1;
    return Math.sqrt(dx*dx + dy*dy);
}

Default parameter values

Any parameter can have a default value, specified with = expr after the parameter name. When the caller omits that argument, the default expression is used. Default arguments must come after required arguments in the parameter list.

func void log(string msg, bool newLine = true) {
    if (newLine) {
        Console.println(msg);
    } else {
        Console.print(msg);
    }
}

log("with newline");        // calls with newLine=true (default)
log("without newline", false);  // calls with newLine=false

Variadic parameters

A parameter declared with ... after its type accepts any number of arguments of that type, collected into an array. Inside the function, the variadic parameter behaves like a regular array. Only the last parameter can be variadic.

func int sum(int... nums) {
    int total = 0;
    foreach (int n in nums) {
        total += n;
    }
    return total;
}

Console.println(sum());           // 0
Console.println(sum(1, 2, 3));    // 6
Console.println(sum(1, 2, 3, 4, 5)); // 15

The ...any form accepts arguments of any type — useful for printf-style functions like StringUtils.format().

Function overloading

Multiple functions can share the same name as long as their parameter lists differ in number or type. The compiler picks the best match based on the argument types at each call site. Overload resolution prefers exact matches over conversions.

func int    max(int a, int b)    { return a > b ? a : b; }
func double max(double a, double b) { return a > b ? a : b; }

Console.println(max(5, 10));        // calls int version → 10
Console.println(max(2.5, 7.5));     // calls double version → 7.5

Generic functions

Functions can be parameterized over types. Type parameters are listed in angle brackets between the return type and the function name (or before the name for class methods). Inside the function, the type parameter can be used like any other type.

// T is a type parameter — the function works for any type
func T identity<T>(T value) {
    return value;
}

int    n = identity(42);      // T inferred as int
string s = identity("hi");     // T inferred as string

// Type inference: the compiler can often infer T from the argument
int    m = identity(99);     // T inferred as int
string t = identity("yo");   // T inferred as string

Generic functions are especially useful for collection algorithms. The standard library's List<T>.map<R>() is a generic method that takes a transform from T to R and returns a List<R>:

List<int> nums = [1, 2, 3, 4, 5];

// map transforms int → int
List<int>  doubled = nums.map(n -> n * 2);

// map transforms int → string
List<string> words = nums.map(n -> $"num: {n}");

Return statements

A return statement exits the function immediately. If the function has a non-void return type, return must be followed by an expression of the correct type. The expression's type is checked at compile time — you can't return a string from a function declared to return int.

func int firstPositive(int a, int b) {
    if (a > 0) return a;
    if (b > 0) return b;
    return 0;   // fallback
}

Recursion

Functions can call themselves. The compiler doesn't apply tail-call optimization, so very deep recursion can overflow the stack — for such cases, prefer an iterative loop.

func int factorial(int n) {
    if (n <= 1) return 1;
    return n * factorial(n - 1);
}

Console.println(factorial(5));   // 120

Functions as values

Functions are first-class values: you can store them in variables, pass them as arguments, and return them from other functions. The type of a function value is written with func<…> or the inline func ReturnType (ParamTypes) form. See Lambdas & Closures for the full treatment.

// Declare a variable that holds a function taking (int, int) → int
func<int, int, int> op;

// Assign a lambda
op = (int a, int b) -> { return a + b; };
Console.println(op(3, 4));   // 7

// Pass a function as an argument
func int apply(func<int, int, int> f, int x, int y) {
    return f(x, y);
}
Console.println(apply(op, 10, 20));   // 30

Methods

When a function is declared inside a class, it's a method. Methods have access to this (the instance the method was called on) and to other members of the class. static methods don't have a this — they're called on the class itself. See Classes for the full method story.

class Calculator {
    public int lastResult;       // instance field

    public func int add(int a, int b) {
        lastResult = a + b;      // 'this' is implicit
        return lastResult;
    }

    public static func int multiply(int a, int b) {
        return a * b;
        // Cannot access 'lastResult' here — no 'this'
    }
}

var c = new Calculator();
Console.println(c.add(2, 3));           // 5 — instance method
Console.println(c.lastResult);          // 5
Console.println(Calculator.multiply(4, 5));  // 20 — static method
