Standard Library

Console & File

Input and output: Console for terminal output and line input, File for reading and writing files on disk. Both are natively backed — the implementations live in the C++ runtime, not in Ume source.

Console is always available

Console is natively backed and always in scope — no import or #include required. File requires the IO module:

import std.io.*;      // AST-level (recommended)
#include <io.ume>      // textual include (C-style)

Console

A static class providing print, println, readLine, and clear. Always available without an import (it's natively backed by the runtime). Output goes to standard out; readLine reads from standard in.

MethodSignatureDescription
printlnpublic static func void println(any msg)Prints msg.toString() followed by a newline.
printpublic static func void print(any msg)Prints msg.toString() without a trailing newline.
readLinepublic static func string readLine()Reads one line from standard in (without the trailing newline). Returns an empty string at EOF.
readLinepublic static func string readLine(string prompt)Prints the prompt, then reads a line.
clearpublic static func void clear()Clears the terminal screen.
 
Console.println("Hello, World!");
Console.print("no newline");
Console.print(" here\n");

Console.println("What's your name?");
string name = Console.readLine();
Console.println("Hi, " + name);

// With a prompt
string city = Console.readLine("City: ");
Console.println("You live in " + city);

Anything you pass to print/println is converted to a string via its toString() method. Numbers, booleans, and strings all have sensible defaults; for your own classes, override toString() to control how they print.

File

A class for reading and writing files. Construct a File with a path, then call the read/write methods. The path can be relative (to the process's current working directory) or absolute. File does not keep the file open between operations — each call opens, operates, and closes.

MethodSignatureDescription
constructorpublic func void constructor(string path)Stores the path; does not open or create the file.
readAllpublic func string readAll()Reads the entire file contents as a single string.
readLinespublic func List<string> readLines()Reads the file and returns a list of lines (without newlines).
writepublic func void write(string content)Overwrites the file with content (creates if missing).
appendpublic func void append(string content)Appends content to the end of the file.
existspublic func bool exists()Returns true if the file exists.
deletepublic func void delete()Deletes the file from disk.
 
File f = new File("notes.txt");

// Write
f.write("line 1\n");
f.append("line 2\n");

// Check existence
if (f.exists()) {
    // Read everything
    string all = f.readAll();
    Console.println(all);

    // Read as lines
    List<string> lines = f.readLines();
    foreach (string line in lines) {
        Console.println("- " + line);
    }
}
For richer filesystem operations

File covers basic read/write. For directory creation, listing, moving, copying, and metadata, use the FileSystem static class from std.system.

A small interactive program

import std.io.*;

func void main() {
    Console.println("=== Note Taker ===");

    // Read existing notes if any
    File f = new File("notes.txt");
    if (f.exists()) {
        Console.println("Current notes:");
        List<string> lines = f.readLines();
        foreach (string line in lines) {
            Console.println("  - " + line);
        }
    }

    // Append a new note
    string note = Console.readLine("New note: ");
    if (note.length() > 0) {
        f.append(note + "\n");
        Console.println("Saved.");
    }
}
