Standard Library

Core (Prelude)

A small set of types and functions that are always available — you don't need to import them. The prelude is loaded automatically before your code runs. It provides the base Exception class, the Pair tuple, the range() and repeat() helpers, and the pre-generics versions of Stack, Queue, and StringBuilder.

Always available

The prelude functions (range, rangeTo, repeat) and classes (Pair, StringBuilder) are natively backed by the interpreter runtime. You do not need any import statement to use them — they are always in scope.

What's in the prelude

The prelude file (stdlib/prelude.ume) declares package std; and contains these declarations. The runtime loads it before your entry point, so all of these are in scope everywhere. Note that Console and basic Math are not in the prelude file — they're natively backed by the C++ runtime and are also always available. See Console & File and Math & Random.

Exception

The base exception type. Custom exceptions extend this. See Exceptions for the full story.

MemberSignatureDescription

constructorpublic func void constructor(string message)Stores the message in the field.

try {
    throw new Exception("something went wrong");
} catch (Exception e) {
    Console.println(e.getMessage());   // something went wrong
}

Pair

A simple two-element tuple. Both fields are typed any, so a single Pair can hold any two values. For type-safe pairs, write your own generic class (see Generics).

MemberSignature
firstpublic any first
secondpublic any second
constructorpublic func void constructor(any a, any b)
toString()public func string toString() — "(a, b)"
 
var p = new Pair("Alice", 30);
Console.println(p.first);    // Alice
Console.println(p.second);   // 30

range() and rangeTo()

Two helper functions that produce a List<int> of consecutive integers. range(start, end) is half-open — start is included, end is excluded. rangeTo(end) is shorthand for range(0, end).

FunctionSignatureReturns
rangepublic func List<int> range(int start, int end)[start, start+1, …, end-1]
rangeTopublic func List<int> rangeTo(int end)[0, 1, …, end-1]
 
var r = range(1, 5);     // [1, 2, 3, 4]
Console.println("range size = " + r.size());  // 4
foreach (int i in range(0, 3)) {
    Console.println(i);      // 0, 1, 2
}

var zeros = rangeTo(3);       // [0, 1, 2]

repeat()

Returns a string consisting of s repeated n times. Useful for simple formatting (indentation, separators).

FunctionSignature
repeatpublic func string repeat(string s, int n)
 
string bar = repeat("-", 20);
Console.println(bar);    // --------------------

string indent = repeat("  ", 3);
Console.println(indent + "indented text");   //       indented text

Pre-generics Stack and Queue

The prelude includes Stack and Queue classes that store any values. These predate the generic versions in std.collections and are kept for backward compatibility. For new code, prefer import std.collections.*; and use Stack<T> / Queue<T> — they're type-safe at compile time.

Stack (any-typed, LIFO)

MethodSignature
pushpublic func void push(any item)
poppublic func any pop() — throws if empty
peekpublic func any peek() — throws if empty
isEmptypublic func bool isEmpty()
sizepublic func int size()
clearpublic func void clear()
toStringpublic func string toString()
 
Stack<int> s = new Stack<int>();
s.push(10);
s.push(20);
Console.println(s.pop());    // 20
Console.println(s.peek());   // 10

// Note: The prelude also provides an untyped Stack (stores any).
// For type safety, use Stack<T> from std.collections instead.

StringBuilder (prelude version)

The prelude also ships a StringBuilder that uses a List<string> internally. The std.string package provides an equivalent StringBuilder — both have the same API. Use whichever is in scope; if you import std.string.*, that version takes precedence.

MethodSignature
constructorpublic func void constructor()
appendpublic func StringBuilder append(any value) — returns this for chaining
appendLinepublic func StringBuilder appendLine(any value) — appends value + newline
clearpublic func void clear()
lengthpublic func int length()
toStringpublic func string toString()
 
var sb = new StringBuilder();
sb.append("name=");
sb.append("Alice");
sb.append("
");
sb.append("age=");
sb.append(30);
Console.println(sb.toString());
// name=Alice
// age=30

// Note: Method chaining (sb.append().append()) may not work reliably
// with the native StringBuilder. Use separate statements instead.
