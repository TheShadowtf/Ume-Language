Standard Library

Audio

Play sounds and music via AudioEngine (the global audio context) and Sound (a playable audio clip). Backed by miniaudio, supporting WAV, MP3, FLAC, and OGG.

Two ways to import
import std.audio.*;   // AST-level (recommended)
#include <audio.ume>   // textual include (C-style)

AudioEngine

The audio engine manages the audio device and mixing. You typically create one AudioEngine for the lifetime of your application and use it to create Sound instances.

MethodSignatureDescription
constructorpublic func void constructor()Initializes the audio device.
setVolumepublic func void setVolume(float volume)Master volume, 0.0 to 1.0.

Sound

A playable audio clip. Construct with the engine and a file path, then control playback with play, stop, volume, pitch, and looping.

MethodSignatureDescription
constructorpublic func void constructor(AudioEngine engine, string filepath)Loads the audio file.
playpublic func void play()Start or resume playback.
stoppublic func void stop()Stop playback.
isPlayingpublic func bool isPlaying()True if currently playing.
setVolumepublic func void setVolume(float volume)Per-sound volume, 0.0 to 1.0.
setPitchpublic func void setPitch(float pitch)Playback speed / pitch. 1.0 = normal.
setLoopingpublic func void setLooping(bool loop)Loop continuously when reaching the end.

Playing background music

import std.audio.*;

func void main() {
    var engine = new AudioEngine();
    engine.setVolume(0.8);

    var music = new Sound(engine, "background.mp3");
    music.setLooping(true);
    music.setVolume(0.7);
    music.play();

    // ... your game loop runs here ...

    // When done:
    music.stop();
}

Sound effects

For short sound effects (jumps, hits, UI clicks), create one Sound per effect and call play() whenever the effect should trigger. Each play() restarts the clip from the beginning:

import std.audio.*;

public class SfxLibrary {
    public Sound jump;
    public Sound coin;

    public SfxLibrary(AudioEngine engine) {
        jump = new Sound(engine, "jump.wav");
        coin = new Sound(engine, "coin.wav");
        jump.setVolume(0.5);
        coin.setVolume(0.5);
    }

    public func void playJump() { jump.play(); }
    public func void playCoin() { coin.play(); }
}
File formats

miniaudio (the backing library) supports WAV, MP3, FLAC, and OGG/Vorbis natively. For best latency on short sound effects, prefer WAV (uncompressed). For music, MP3 or OGG save memory at the cost of decode overhead.
