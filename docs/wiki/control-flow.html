Language

Control Flow

Ume has the standard set of structured control-flow constructs: if/else for branching, while and do/while for pre- and post-condition loops, for for C-style counting loops, foreach for iteration, and switch for multi-way dispatch.

if / else

An if statement evaluates a boolean condition and runs the then-branch if it's true. An optional else clause runs when the condition is false. else if chains are just an else containing another if — there's no separate keyword.

int x = 10;

if (x > 0) {
    Console.println("positive");
} else if (x < 0) {
    Console.println("negative");
} else {
    Console.println("zero");
}

// Single-statement bodies can omit braces (braces preferred for readability)
if (x > 100) Console.println("big");

The condition must be a bool — there's no implicit int-to-bool conversion. if (x) where x is an int is a compile error; you must write if (x != 0).

while

A while loop evaluates its condition before each iteration. If the condition is false on the first check, the body never runs. The condition must be a bool.

int i = 0;
while (i < 5) {
    Console.println(i);
    i++;
}

do / while

A do/while loop runs its body first, then checks the condition. This guarantees the body executes at least once, even if the condition is initially false. The condition follows while and the statement ends with a semicolon.

int n = 0;
do {
    Console.println("executed at least once");
    n++;
} while (n < 3);

for (C-style)

The classic three-part for loop: initializer, condition, update. The initializer runs once before the first iteration; the condition is checked before each iteration (including the first); the update runs after each iteration. Any of the three parts can be omitted.

for (int i = 0; i < 5; i++) {
    Console.println(i);
}

// Multiple variables in the initializer
for (int i = 0, j = 10; i < j; i++, j--) {
    Console.println($"i={i}, j={j}");
}

// Omitted condition means an infinite loop (use break to exit)
for (int i = 0; ; i++) {
    if (i >= 100) break;
}

foreach

A foreach loop iterates over every element of a collection — arrays, List<T>, Set<T>, the keys()/values() of a Map, and any other iterable type. The element type and a variable name are declared, then in, then the iterable expression.

List<string> names = new List<string>();
names.add("Alice");
names.add("Bob");
names.add("Charlie");

foreach (string name in names) {
    Console.println("Hello, " + name);
}

// Works on arrays too
int[] nums = [10, 20, 30];
foreach (int n in nums) {
    Console.println(n);
}

You can use var as the element type to let the compiler infer it:

foreach (var item in mixedList) {
    Console.println(item.toString());
}

switch

A switch statement evaluates an expression and jumps to the matching case label. Cases compare by equality. Each case ends with break (or another terminating statement like return) to prevent fall-through; if you forget the break, execution continues into the next case. A default case handles values that don't match any case.

int day = 2;
switch (day) {
    case 1: Console.println("Monday");    break;
    case 2: Console.println("Tuesday");   break;
    case 3: Console.println("Wednesday"); break;
    case 4: Console.println("Thursday");  break;
    case 5: Console.println("Friday");    break;
    default: Console.println("Weekend");
}

Switch works on strings too:

string cmd = "go";
switch (cmd) {
    case "go":   startEngine(); break;
    case "stop": stopEngine();  break;
    case "quit": exit(0);       break;
    default: Console.println("unknown command");
}

break

Exits the innermost enclosing while, do/while, for, foreach, or switch. Execution continues at the statement after the loop or switch.

for (int i = 0; i < 100; i++) {
    if (i == 42) {
        Console.println("found it");
        break;
    }
}

continue

Skips the rest of the current iteration of the innermost loop and proceeds to the next iteration. In a for loop, the update part runs before the next condition check.

for (int i = 0; i < 10; i++) {
    if (i % 2 == 0) continue;   // skip even numbers
    Console.println(i);         // prints 1, 3, 5, 7, 9
}

Early return

A return statement exits the enclosing function immediately, regardless of any surrounding loops. It's the idiomatic way to short-circuit out of a function when a condition is met.

func int indexOf(int[] arr, int target) {
    for (int i = 0; i < arr.length(); i++) {
        if (arr[i] == target) {
            return i;   // exit immediately
        }
    }
    return -1;          // not found
}

throw

A throw statement raises an exception, immediately unwinding the call stack until a matching catch is found (or the program terminates). See Exceptions for the full story.

func int divide(int a, int b) {
    if (b == 0) {
        throw new Exception("Division by zero");
    }
    return a / b;
}

Nested control flow

All control-flow constructs can be nested arbitrarily. Loops inside loops, if inside switch inside for — anything goes. The break and continue keywords always refer to the innermost enclosing loop or switch.

List<int> grid = new List<int>();
for (int row = 0; row < 3; row++) {
    for (int col = 0; col < 3; col++) {
        if (row == col) continue;     // skips diagonal
        grid.add(row * 10 + col);
    }
}
// grid contains: 1, 2, 10, 12, 20, 21
