Concurrency

Multi-threaded programming with Thread, Mutex, ConditionVariable, AtomicInt, and Task<T> for asynchronous results.

Two ways to import
import std.thread.*;   // AST-level (recommended)
#include <thread.ume>   // textual include (C-style)

Note: Thread.sleep(ms) is a static method and is always available without import.

Thread

A thread runs a function concurrently with the calling thread. Construct a Thread with the function to run, then call start() to begin execution. Call join() to wait for the thread to finish. Threads share memory with their parent — that's why you need mutexes and atomics for synchronization.

MethodSignatureDescription
constructorpublic func void constructor(func void () task)Stores the task; doesn't start yet.
startpublic func void start()Begins running the task on a new OS thread.
joinpublic func void join()Blocks until the thread finishes.
isAlivepublic func bool isAlive()True if the thread is still running.
sleeppublic static func void sleep(long milliseconds)Pause the current thread.
currentpublic static func Thread current()The currently-running thread.
 
import std.thread.*;

public class Main {
    public static func void main() {
        var worker = () -> {
            for (int i = 0; i < 5; i++) {
                Console.println("worker: " + i);
                Thread.sleep(100);
            }
        };

        var t = new Thread(worker);
        t.start();

        // Do other work in parallel
        Console.println("main: started worker");

        t.join();   // wait for worker to finish
        Console.println("main: done");
    }
}

Mutex

A mutual-exclusion lock. Only one thread can hold the lock at a time; others block on lock() until it's released. Use a mutex to protect shared mutable state — any code that reads or writes shared data should acquire the lock first.

MethodSignature
constructorpublic func void constructor()
lockpublic func void lock() — blocks until acquired
unlockpublic func void unlock()
tryLockpublic func bool tryLock() — non-blocking; returns false if not acquired
 
import std.thread.*;

Mutex mtx = new Mutex();
int sharedCounter = 0;

var worker = () -> {
    for (int i = 0; i < 1000; i++) {
        mtx.lock();
        sharedCounter++;
        mtx.unlock();
    }
};

var t1 = new Thread(worker);
var t2 = new Thread(worker);
t1.start(); t2.start();
t1.join();  t2.join();

Console.println(sharedCounter);   // 2000 — no lost updates

AtomicInt

An integer whose reads and writes are atomic — safe to use from multiple threads without a mutex. Operations like getAndIncrement and compareAndSet are lock-free and use CPU atomic instructions. Prefer AtomicInt over a mutex-protected int when you only need atomic counter semantics.

MethodSignatureDescription
constructorpublic func void constructor(int initialValue)Initial value.
getpublic func int get()Read the current value.
setpublic func void set(int value)Write the value.
addAndGetpublic func int addAndGet(int delta)Add delta, return new value.
getAndIncrementpublic func int getAndIncrement()Return old value, then increment.
getAndDecrementpublic func int getAndDecrement()Return old value, then decrement.
compareAndSetpublic func bool compareAndSet(int expected, int update)If value == expected, set to update and return true; else return false.
 
import std.thread.*;

AtomicInt counter = new AtomicInt(0);

var worker = () -> {
    for (int i = 0; i < 1000; i++) {
        counter.getAndIncrement();
    }
};

var t1 = new Thread(worker);
var t2 = new Thread(worker);
t1.start(); t2.start();
t1.join();  t2.join();

Console.println(counter.get());   // 2000 — no data race

ConditionVariable

For more complex synchronization than a simple mutex allows — wait/notify patterns where one thread waits for a condition and another signals when the condition might be true. A thread calling wait(m) atomically releases the mutex m and blocks; signal() wakes one waiting thread; broadcast() wakes all of them.

MethodSignature
constructorpublic func void constructor()
waitpublic func void wait(Mutex m)
signalpublic func void signal()
broadcastpublic func void broadcast()

Task<T>

A future-like wrapper for asynchronous computation. Construct a Task<T> with a function returning T; the function runs (potentially on another thread) and get() blocks until the result is ready. Use isDone() to check without blocking.

MethodSignatureDescription
constructorpublic func void constructor()Empty task.
getpublic func T get()Block until done, return the result.
waitpublic func void wait()Block until done (no return value).
isDonepublic func bool isDone()True if the task has completed.
 
import std.thread.*;

var task = new Task<int>(() -> {
    // expensive computation
    int result = 0;
    for (int i = 0; i < 1000000; i++) {
        result += i;
    }
    return result;
});

// Do other work while the task runs...
Console.println("computing in background...");

// Block for the result
int sum = task.get();
Console.println($"sum = {sum}");   // sum = 1783293664
Concurrent code is hard

Multi-threaded bugs — data races, deadlocks, livelocks — are among the hardest to diagnose because they're often non-deterministic. Reach for AtomicInt first (it's the simplest correct option for counters). Use Mutex when you need to protect a multi-step operation. Keep critical sections short, and never hold a lock while doing I/O.
