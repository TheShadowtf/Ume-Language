Standard Library

Collections

Generic, type-safe collection types: List<T> (ordered, indexable), Map<K,V> (key-value), Set<T> (unique values), Stack<T> (LIFO), and Queue<T> (FIFO).

Two ways to import
import std.collections.*;   // AST-level (recommended)
#include <collections.ume>  // textual include (C-style)

List<T>

A dynamic array — the workhorse collection. Elements are stored contiguously and accessible by integer index. Adding to the end is amortized O(1); inserting or removing from the middle is O(n).

MethodSignatureDescription
constructorpublic func void constructor()Empty list.
addpublic func void add(T item)Append to end.
getpublic func T get(int index)Read element at index (throws if out of range).
setpublic func void set(int index, T item)Overwrite element at index.
sizepublic func int size()Number of elements.
isEmptypublic func bool isEmpty()True if size is 0.
containspublic func bool contains(T item)Linear search for equality.
removepublic func void remove(int index)Remove element at index, shifting later elements left.
removeItempublic func void removeItem(T item)Remove first element equal to item.
clearpublic func void clear()Remove all elements.
indexOfpublic func int indexOf(T item)Index of first equal element, or -1.
slicepublic func List<T> slice(int start, int end)New list with elements [start, end).
sortpublic func void sort(func int (T, T)? comparator)In-place sort; null comparator uses natural order.
forEachpublic func void forEach(func void (T) action)Apply action to each element.
filterpublic func List<T> filter(func bool (T) predicate)New list with elements matching predicate.
mappublic func List<R> map<R>(func R (T) transform)New list of transformed values.
reducepublic func R reduce<R>(R initial, func R (R, T) accumulator)Fold left over the list.
 
import std.collections.*;

List<int> nums = new List<int>();
nums.add(1); nums.add(2); nums.add(3); nums.add(4); nums.add(5);

Console.println(nums.size());      // 5
Console.println(nums.get(2));      // 3
nums.set(0, 99);
Console.println(nums.get(0));      // 99

// Functional pipeline
List<int> evens   = nums.filter(n -> n % 2 == 0);   // [2, 4]
List<int> doubled = nums.map(n -> n * 2);       // [198, 4, 6, 8, 10]
int sum          = nums.reduce(0, (acc, n) -> acc + n);  // 113

// Sort with a comparator
List<int> messy = new List<int>();
messy.add(3); messy.add(1); messy.add(4); messy.add(1); messy.add(5);
messy.sort((a, b) -> a - b);    // ascending
Console.println(messy.get(0));   // 1

Map<K, V>

A key-value mapping. Looking up by key is O(1) average. Keys must be hashable (strings, integers, and other built-in types work). Insertion order is not guaranteed.

MethodSignatureDescription
constructorpublic func void constructor()Empty map.
putpublic func void put(K key, V value)Insert or overwrite.
getpublic func V get(K key)Fetch value; throws if absent.
getOrNullpublic func V? getOrNull(K key)Fetch value or null.
containsKeypublic func bool containsKey(K key)True if key exists.
containsValuepublic func bool containsValue(V value)Linear search over values.
removepublic func void remove(K key)Delete entry by key.
sizepublic func int size()Number of entries.
isEmptypublic func bool isEmpty()True if empty.
clearpublic func void clear()Remove all entries.
keyspublic func List<K> keys()All keys as a list.
valuespublic func List<V> values()All values as a list.
forEachpublic func void forEach(func void (K, V) action)Iterate over (key, value) pairs.
 
Map<string, int> scores = new Map<string, int>();
scores.put("Alice", 95);
scores.put("Bob", 82);
scores.put("Charlie", 78);

Console.println(scores.get("Alice"));        // 95
Console.println(scores.containsKey("Bob"));  // true
Console.println(scores.size());              // 3

// Safe lookup
int? maybe = scores.getOrNull("Dave");
if (maybe == null) {
    Console.println("Dave not found");
}

// Iterate
scores.forEach((k, v) -> {
    Console.println(k + ": " + v);
});

Set<T>

A collection of unique values. Adding a value that's already present has no effect. Membership checks are O(1) average.

MethodSignatureDescription
constructorpublic func void constructor()Empty set.
addpublic func void add(T item)Add if not present.
containspublic func bool contains(T item)O(1) membership.
removepublic func void remove(T item)Remove if present.
sizepublic func int size()Number of elements.
isEmptypublic func bool isEmpty()True if empty.
clearpublic func void clear()Remove all.
toListpublic func List<T> toList()Snapshot as a list.
forEachpublic func void forEach(func void (T) action)Iterate.
unionpublic func Set<T> union(Set<T> other)New set with elements from both.
intersectpublic func Set<T> intersect(Set<T> other)New set with elements in both.
differencepublic func Set<T> difference(Set<T> other)New set with elements in this but not other.
 
Set<string> tags = new Set<string>();
tags.add("ume");
tags.add("language");
tags.add("ume");          // duplicate — ignored

Console.println(tags.size());      // 2
Console.println(tags.contains("ume"));   // true

// Set operations
Set<int> a = new Set<int>();
a.add(1); a.add(2); a.add(3);
Set<int> b = new Set<int>();
b.add(2); b.add(3); b.add(4);

Set<int> u = a.union(b);          // {1, 2, 3, 4}
Set<int> i = a.intersect(b);      // {2, 3}
Set<int> d = a.difference(b);     // {1}

Stack<T>

Last-in, first-out. push adds to the top, pop removes from the top.

MethodSignature
constructorpublic func void constructor()
pushpublic func void push(T item)
poppublic func T pop() — throws if empty
peekpublic func T peek() — throws if empty
isEmptypublic func bool isEmpty()
sizepublic func int size()
clearpublic func void clear()
 
Stack<int> s = new Stack<int>();
s.push(10);
s.push(20);
s.push(30);
Console.println(s.pop());    // 30
Console.println(s.peek());   // 20

// Note: Stack and Queue are natively backed as List objects.
// You can also use the prelude's untyped Stack/Queue (any elements):
//   Stack ps = new Stack();  // prelude version, stores any
//   ps.push(10); ps.push("hi");

Queue<T>

First-in, first-out. enqueue adds to the back, dequeue removes from the front.

MethodSignature
constructorpublic func void constructor()
enqueuepublic func void enqueue(T item)
dequeuepublic func T dequeue() — throws if empty
frontpublic func T front() — throws if empty
isEmptypublic func bool isEmpty()
sizepublic func int size()
clearpublic func void clear()
 
Queue<string> q = new Queue<string>();
q.enqueue("first");
q.enqueue("second");
q.enqueue("third");
Console.println(q.dequeue());   // first
Console.println(q.front());     // second
