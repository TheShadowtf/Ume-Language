Attributes & Annotations

Attributes (also known as annotations) attach metadata to declarations. Ume supports both Java-style @Annotation syntax and C#-style [Attribute] syntax. Several built-in annotations drive compiler verification and code generation, including @Override, @FunctionalInterface, @Deprecated, and @Serializable.

Syntax

You can write attributes using either Java-style (@Name) or C#-style ([Name]). Both can take arguments: @Name(args) or [Name(args)]. You can stack multiple annotations on separate lines or combine bracketed attributes with commas.

// Java style:
@Serializable
public class User {
    @JsonProperty("user_id")
    public int id;

    @JsonProperty("username")
    public string name;
}

// Equivalent C# style:
[Serializable]
public class User2 {
    [JsonProperty("user_id")]
    public int id;
}

Built-in annotations

AnnotationTargetBehavior
@OverrideMethodMarks an overridden method. The compiler/interpreter validates that the method exists in a superclass or interface hierarchy. Overriding methods must be marked with override or @Override.
@FunctionalInterfaceInterfaceValidates that an interface declares exactly one abstract method (ideal for lambdas). Fails compile-time/interpret-time if it has 0 or >1 abstract methods.
@DeprecatedAny declarationMarks a symbol as deprecated, emitting a compiler/interpreter warning upon usage. Accepts an optional message argument: @Deprecated("use newFunc()").
@SerializableClassGenerates toJsonString() and static fromJsonString() at compile time.
@JsonPropertyFieldSpecifies a custom JSON field name during serialization/deserialization.

@Override

When implementing interface methods or overriding superclass methods, marking them is mandatory. Using @Override (or the override keyword) guarantees that you don't accidentally introduce subtle bugs:

abstract class Vehicle {
    public abstract func void drive(int speed);
}

class ElectricCar extends Vehicle {
    // Valid override:
    @Override
    public func void drive(int speed) {
        Console.println("Driving at " + speed);
    }

    // Compile error: typo in method name or parameter mismatch!
    @Override
    public func void drve(int speed) {}
    // error: Method 'drve' marked with 'override' or '@Override' does not override or implement any method from a supertype
}

@FunctionalInterface

Applied to an interface, @FunctionalInterface guarantees that the interface is suitable for single-method lambda contracts. If the interface contains zero or more than one abstract method, the compiler immediately rejects it:

@FunctionalInterface
public interface Action {
    func void execute();
}

// Error if violated:
@FunctionalInterface
public interface BadAction {
    func void stepOne();
    func void stepTwo(); // error: Interface contains 2 abstract methods (expected 1)
}

[Serializable] / @Serializable

Applying @Serializable (or [Serializable]) to a class tells the compiler to generate two methods automatically:

  • toJsonString() — serializes the instance to a JSON string.
  • fromJsonString(string json) — static method that parses a JSON string and returns a new instance.
@Serializable
public class Product {
    @JsonProperty("product_id")
    public int id;

    @JsonProperty("display_name")
    public string name;

    @JsonProperty("price_usd")
    public double price;
}

public class Main {
    public static func void main() {
        var p = new Product();
        p.id    = 101;
        p.name  = "Widget";
        p.price = 19.99;

        // Serialize to JSON
        string json = p.toJsonString();
        Console.println(json);
        // {"product_id":101,"display_name":"Widget","price_usd":19.99}

        // Deserialize back
        var p2 = Product.fromJsonString(json);
        Console.println(p2.name);    // Widget
        Console.println(p2.price);   // 19.99
    }
}

Custom attributes

Attribute syntax supports any name, so you can attach arbitrary metadata to declarations for your own tooling or code generators to consume:

@Experimental
@Deprecated("use NewClass instead")
public class OldClass {
    @Range(0, 100)
    public int percentage;
}
