Standard Library

String Utilities

StringUtils provides parsing, padding, joining, and formatting. StringBuilder is the efficient way to build long strings from many pieces.

Two ways to import
import std.string.*;   // AST-level (recommended)
#include <string.ume>   // textual include (C-style)

Note: StringBuilder is also available natively without any import — it is always in scope as part of the prelude.

StringUtils

A static class with utility methods for working with strings. All methods are static — call them on the class name, not on an instance.

MethodSignatureDescription
parseIntpublic static func int parseInt(string s)Parse an integer. Throws if the string isn't a valid int.
parseDoublepublic static func double parseDouble(string s)Parse a double.
parseBoolpublic static func bool parseBool(string s)Parse "true"/"false" (case-insensitive).
isIntpublic static func bool isInt(string s)True if the string is a valid integer.
isNumberpublic static func bool isNumber(string s)True if the string is a valid number (int or float).
repeatpublic static func string repeat(string s, int n)s concatenated n times.
padLeftpublic static func string padLeft(string s, int width, char pad)Left-pad s to width with pad.
padRightpublic static func string padRight(string s, int width, char pad)Right-pad s to width with pad.
joinpublic static func string join(List<string> parts, string separator)Join strings with a separator.
formatpublic static func string format(string template, ...any args)Replace {0}, {1}, … with args.
 
import std.string.*;

// Parsing
int    n = StringUtils.parseInt("42");
double d = StringUtils.parseDouble("3.14");
bool   b = StringUtils.parseBool("true");

// Validation
Console.println(StringUtils.isInt("123"));     // true
Console.println(StringUtils.isInt("12.3"));    // false
Console.println(StringUtils.isNumber("12.3")); // true

// Padding
Console.println(StringUtils.padLeft("42", 5, '0'));    // 00042
Console.println(StringUtils.padRight("hi", 6, '.'));   // hi....

// Join
List<string> parts = new List<string>();
parts.add("a"); parts.add("b"); parts.add("c");
Console.println(StringUtils.join(parts, ", "));   // a, b, c

// Format with {0}, {1}, ... placeholders
string msg = StringUtils.format("Hello, {0}! You are {1} years old.", "Alice", 30);
Console.println(msg);
// Hello, Alice! You are 30 years old.

// format() supports both {0}, {1} (indexed) and {} (sequential) placeholders.

StringBuilder

For building long strings from many pieces. Repeated + concatenation creates a new string each time, which is O(n²) for n concatenations. StringBuilder accumulates pieces internally and only materializes the final string when you call toString(), making it O(n).

MethodSignatureDescription
constructorpublic func void constructor()Empty builder.
appendpublic func StringBuilder append(any value)Append value.toString(). Returns this for chaining.
appendLinepublic func StringBuilder appendLine(any value)Append value + newline.
clearpublic func void clear()Reset to empty.
lengthpublic func int length()Total character count.
toStringpublic func string toString()Materialize the accumulated string.
 
import std.string.*;

// Building a report
StringBuilder sb = new StringBuilder();
sb.appendLine("=== Report ===");
sb.append("Name: ").appendLine("Alice");
sb.append("Score: ").append(95).append("/").appendLine(100);
sb.appendLine("---");

Console.println(sb.toString());
// === Report ===
// Name: Alice
// Score: 95/100
// ---

Method chaining works because append and appendLine return this:

string csv = new StringBuilder()
    .append("a,b,c\n")
    .append("1,2,3\n")
    .append("4,5,6\n")
    .toString();
Console.println(csv);
