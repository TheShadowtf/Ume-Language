Time

Time utilities for measuring frame time, fixed timesteps, delays, and elapsed time in milliseconds and seconds.

Importing
import std.time.*;

Time

The Time class provides static utilities for high-precision time measurements.

MethodSignatureDescription
millispublic static func long millis()Returns current system time in milliseconds.
secondspublic static func double seconds()Returns current time in seconds as a double.

Fixed Timestep Example

import std.time.*;

double lastTime = Time.seconds();
double timeStep = 1.0 / 60.0;
double accumulator = 0.0;

while (running) {
    double now = Time.seconds();
    double frameTime = now - lastTime;
    lastTime = now;
    accumulator += frameTime;

    while (accumulator >= timeStep) {
        // Fixed 60Hz physics step
        updatePhysics(timeStep);
        accumulator -= timeStep;
    }

    render();
}
