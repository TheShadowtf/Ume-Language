Vectors

Two- and three-dimensional float vector types with arithmetic, dot product, cross product (3D), length, and normalization.

Two ways to import
import std.vector.*;   // AST-level (recommended)
#include <vector.ume>   // textual include (C-style)

Vector2

A 2D vector with float components x and y.

MemberSignatureDescription
fieldspublic float x, yDirectly accessible.
constructorpublic func void constructor(float x, float y)
addpublic func Vector2 add(Vector2 other)Component-wise addition.
subpublic func Vector2 sub(Vector2 other)Component-wise subtraction.
mulpublic func Vector2 mul(float scalar)Scalar multiplication.
dotpublic func float dot(Vector2 other)Dot product.
lengthpublic func float length()Magnitude.
normalizedpublic func Vector2 normalized()Unit vector in the same direction; returns (0,0) if length is 0.
 
import std.vector.*;

Vector2 a = new Vector2(3.0, 4.0);
Vector2 b = new Vector2(1.0, 1.0);

Console.println(a.length());         // 5.0  (3-4-5 triangle)

Vector2 sum = a.add(b);
Console.println($"({sum.x}, {sum.y})");   // (4.0, 5.0)

Vector2 dir = a.normalized();
Console.println($"({dir.x}, {dir.y})");   // (0.6, 0.8)

float d = a.dot(b);
Console.println(d);                  // 7.0

Vector3

A 3D vector with float components x, y, z. Adds the cross product (which is only meaningful in 3D).

MemberSignatureDescription
fieldspublic float x, y, z
constructorpublic func void constructor(float x, float y, float z)
addpublic func Vector3 add(Vector3 other)
subpublic func Vector3 sub(Vector3 other)
mulpublic func Vector3 mul(float scalar)
dotpublic func float dot(Vector3 other)
crosspublic func Vector3 cross(Vector3 other)Cross product — yields a vector perpendicular to both inputs.
lengthpublic func float length()
normalizedpublic func Vector3 normalized()
 
import std.vector.*;

Vector3 x = new Vector3(1.0, 0.0, 0.0);
Vector3 y = new Vector3(0.0, 1.0, 0.0);

// Cross product: x × y = z
Vector3 z = x.cross(y);
Console.println($"({z.x}, {z.y}, {z.z})");   // (0.0, 0.0, 1.0)

// Length and normalization
Vector3 v = new Vector3(3.0, 4.0, 12.0);   // 5-12-13 pyramid: length = 13
Console.println(v.length());               // 13.0

Vector3 unit = v.normalized();
Console.println(unit.length());            // 1.0

When to use these

The Vector2/Vector3 classes are convenient for game logic, physics calculations, and geometry. They use float precision, which is the standard choice for real-time graphics. For double-precision work, write your own equivalent class — or use the techniques from Operator Overloading to build a richer vector type that supports +, -, * directly.
