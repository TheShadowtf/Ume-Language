Primitive Types

Ume is statically typed. Every variable, parameter, field, and return value has a type known at compile time. The built-in primitive types cover numeric, textual, and boolean values; user-defined types (classes, structs, enums, interfaces) build on top of these.

Numeric types

Ume provides the standard C-family numeric types. Sizes follow the C++17 <cstdint> conventions on the target platform — on Windows/MSVC, int and long are both 32 bits.

TypeKindTypical widthExample
intSigned integer32 bitsint x = 42;
longSigned integer32 or 64 bits (platform)long ms = 1700000000L;
shortSigned integer16 bitsshort s = 1000;
byteSigned integer8 bitsbyte b = 255;
floatFloating point32 bits (IEEE 754)float f = 3.14f;
doubleFloating point64 bits (IEEE 754)double pi = 3.14159;

Integer literals can be written in decimal or hexadecimal (0x prefix). A trailing f on a numeric literal makes it a float; without it, a literal containing a decimal point or exponent is a double, and one without either is an int.

int    dec   = 255;
int    hex   = 0xFF;        // 255
double pi    = 3.14159;
double sci   = 1.5e3;       // 1500.0
float  half  = 0.5f;
long   big   = 9000000000;

bool

The boolean type has two values: true and false. It's the type of comparison results, logical operators, and conditions in if/while/for. There's no implicit conversion between bool and integers — you must compare explicitly.

bool ready  = true;
bool empty  = (0 == 0);
bool larger = (10 > 5) && (3 != 4);

if (ready) {
    Console.println("go");
}

char

A single character, written with single quotes. Supports the standard escape sequences. char is a value type — assigning one char to another copies the value.

char letter = 'A';
char nl     = '\n';
char tab    = '\t';
char nul    = '\0';
char quote  = '\'';

Console.println(letter);    // A

string

A reference type holding a sequence of characters. String literals use double quotes and support the same escape sequences as char. Strings are immutable in the standard library sense — operations like concatenation produce new strings rather than mutating in place. See Strings & Interpolation for the full story including the $"…{expr}…" interpolation syntax.

string name  = "Alice";
string path  = "C:\\temp\\file.txt";
string multi = "line1\nline2";

// String concatenation with +
string full = "Hello, " + name + "!";

// Length is a method
Console.println(name.length());   // 5

void

Used only as a return type on functions (and as a parameter list indicator). It means "this function does not return a value". You cannot declare a variable of type void.

func void log(string msg) {
    Console.println(msg);
    // no return statement, or just `return;`
}

any

A type-erased reference that can hold any value. any is Ume's escape hatch when you genuinely don't know (or don't care about) the static type at compile time — for example, a heterogeneous collection or a parameter that accepts anything. You pay for this with runtime dispatch: method calls on an any are resolved dynamically by the interpreter, and statically-typed code generation may emit runtime type checks.

any box = 42;            // holds an int
box   = "now a string";   // holds a string
box   = new List<int>();  // holds a List<int>

Console.println(box.toString());   // safe — everything has toString

Because any bypasses static checking, prefer generics over any whenever you can express the same idea generically. A List<int> is always preferable to a List<any> — the former is type-safe at compile time, the latter will happily let you put a string in and crash on retrieval.

Nullable types T?

Any reference type (and int?, long?, etc.) can be made nullable by appending a ? to the type. A nullable variable can hold either a valid value of the base type or null. The compiler treats nullable and non-nullable as distinct types — you cannot assign null to a non-nullable variable without an explicit cast.

string  name    = "Alice";     // non-nullable — cannot be null
string? nickname = null;        // nullable — can be null or a string

// Safe: nullable to nullable
string? a = nickname;

// Unsafe without a check — would need an explicit cast or null-coalesce
// string b = nickname;   // ← rejected: nickname might be null

// Null-coalesce: provide a default when null
string display = nickname ?? "Anonymous";

// Safe navigation: method call that's skipped if null
int? len = nickname?.length();   // null if nickname is null, else its length

For the full set of null-safety operators (??, ?., !), see Expressions & Operators → Null safety.

Array types T[]

Append [] to a type to get a dynamic array of that type. You can also give a fixed size with T[N]. Arrays support indexing with [] and have a .length() method. Array literals are written with square brackets: [1, 2, 3].

int[]  nums   = [10, 20, 30];
string[] names = ["Alice", "Bob"];

Console.println(nums[0]);       // 10
nums[1] = 99;
Console.println(nums.length()); // 3

// Fixed-size array type
double[5] samples;

Pointer types T* (unsafe)

Raw pointers exist but are only usable inside unsafe blocks. They're intended for C++ interop and manual memory management. The pointer level can be stacked (int**). See Unsafe Blocks for the full story.

unsafe {
    int* p = alloc<int>(4);
    *p = 42;
    Console.println(*p);
    free(p);
}

Function types func<…>

You can declare variables and parameters that hold function values. There are two equivalent syntaxes — the angle-bracket form and the inline form. The angle-bracket form lists the return type first, then the parameter types; the inline form writes the return type, then the parameter types in parentheses.

// Both declare: a function that takes two ints and returns an int
func<int, int, int> op1;
func int (int, int) op2;

// Assigning a lambda
op1 = (int a, int b) -> { return a + b; };
Console.println(op1(3, 4));   // 7

See Lambdas & Closures for the full treatment.
